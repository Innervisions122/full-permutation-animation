# 全排列递归动画

以 `n = 3` 为例，逐步展示全排列算法的递归调用与回溯过程，帮助理解 `FullArray(index)`、调用栈以及 `array`、`symbol` 的变化。

## 功能

- 自动播放、暂停、上一步、下一步和从头开始。
- 支持慢、正常、快三种播放速度。
- 拖动进度条跳转到任意步骤。
- 展示当前递归层及各层独立的循环变量 `i`。
- 高亮当前执行的 C 代码。
- 展示共享数组 `array`、`symbol` 的状态和修改。
- 按字典序生成并展示全部 6 个排列。

## 如何理解动画

### 两个共享数组

- `array[index]`：当前排列中，第 `index` 个位置保存的数字。
- `symbol[i]`：数字 `i + 1` 是否已经使用。`1` 表示占用，`0` 表示可选。

所有递归层共享同一份 `array` 和 `symbol`，但每次函数调用都有自己的 `index` 和 `i`。

### 递归层

| 函数调用 | 任务 |
| --- | --- |
| `FullArray(0)` | 填写第一个位置 |
| `FullArray(1)` | 填写第二个位置 |
| `FullArray(2)` | 填写第三个位置 |
| `FullArray(3)` | 输出完整排列，然后返回 |

### 颜色与标记

- **蓝色实线**：当前位置已选定，或对应数字已占用。
- **虚线**：当前位置未选定、保留旧值，或对应数字可选。
- **黄色**：本步骤刚修改的数组元素。
- **调用栈中的蓝色区域**：当前正在执行的递归层。

## 重点观察：return 不会恢复数组

核心代码为：

```c
array[index] = i + 1;
symbol[i] = 1;

FullArray(index + 1);

symbol[i] = 0;
```

递归返回后：

1. `return` 本身不会清空或恢复 `array`、`symbol`。
2. `symbol[i] = 0` 主动取消当前数字的占用标记。
3. `array[index]` 保留旧值，直到下一次选择时被覆盖。

因此，动画中可能暂时出现 `[1, 3, 3]`。这不是错误：最后一个 `3` 是尚未覆盖的旧值，不属于当前已经选好的部分。只有所有位置都重新填好后，程序才输出排列。

